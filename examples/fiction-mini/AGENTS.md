# CreativeSDD作品ガイド

- 人間が読む自然言語は日本語、機械が扱う名前は英語にする。
- ユーザーにCreativeSDD用Markdownを手書きさせず、会話からAIが提案・更新する。
- SpecとPlanは、内容を提示した後の明示的な承認なしに`approved`へ変更しない。
- 原稿は`manuscript/`へ保存し、一度に一つのWriting Taskだけを扱う。
- 原稿受理後だけcontinuity、summary、必要なcanon、将来計画をReconcileする。
- OutlineとTaskの予定より、受け入れ済み原稿上の現実を優先する。
- Reviewは原稿を変更せず、Revisionは`approved`な指摘だけを必要最小限に反映する。
- 外部DB、RAG、Embedding、独自エージェントランタイムを追加しない。
